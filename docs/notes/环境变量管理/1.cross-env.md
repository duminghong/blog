# cross-env {#cross-env-title}

`cross-env` 是一个跨平台的环境变量管理工具，它可以在不同的操作系统上使用相同的环境变量。

## 安装 {#install}

```bash
npm install cross-env --save-dev
```

## 使用 {#use}

- **语法**：`cross-env 变量=值 命令`
- **读取**：`process.env.变量名`

::: code-group

```bash [终端]
cross-env NODE_ENV=development npm run dev
```

```json [package.json]
{
  "name": "demo",
  "scripts": {
    "dev": "cross-env NODE_ENV=dev PORT=3000 node app.js",
    "prod": "cross-env NODE_ENV=prod PORT=80 node app.js"
  },
  "devDependencies": {
    "cross-env": "^7.0.3"
  }
}
```

```javascript [app.js]
console.log("当前环境：", process.env.NODE_ENV)
console.log("端口号：", process.env.PORT)
```

:::
